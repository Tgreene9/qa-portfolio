# TAU: Introduction to pytest

Code-along for [Introduction to pytest](https://testautomationu.applitools.com/pytest-tutorial/) (Andrew Knight, Test Automation University).

## Run

From the repo root, with the virtual environment active:

```bash
pytest tau-pytest
```
